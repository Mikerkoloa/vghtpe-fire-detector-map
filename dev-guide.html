更新圖資

更新 PDF 後重建索引

新增、刪除或替換 火警圖 PDF/ 資料夾內的檔案後：

node scripts/build-index.js

會重新產生：

檔案用途
data/fire-map-index.json探測器文字標籤與 PDF 座標
data/buildings.json棟別與樓層清單
⚠️ 不重建索引的話，搜尋不會出現新的 PDF 資料。

版本控制

推送到 GitHub

一鍵推送（預設訊息 "update"）

npm run push

自訂 commit 訊息

powershell -File scripts/push.ps1 -Message "更新長青樓B1F火警圖"

手動推送

git add -A
git commit -m "你的訊息"
git push
⚠️ 推送前請確認 火警圖 PDF/ 內沒有不該公開的機密資料。整個 repo 是公開的。

部署

Vercel 部署

GitHub 推送後 Vercel 會自動重新部署（已綁定 main 分支）。

https://vghtpe-fire-detector-map.vercel.app

如果自動部署沒觸發，可以手動：

npx vercel --prod
⚠️ 部署後瀏覽器可能有快取，按 Ctrl + F5 強制重新整理。

系統管理

Windows 背景執行與開機啟動

背景啟動 npm run win:start
查看狀態 npm run win:status
停止服務 npm run win:stop
註冊開機自動啟動 npm run win:register
取消自動啟動 npm run win:unregister

記錄檔

路徑內容
logs/server.out.log正常輸出
logs/server.err.log錯誤輸出
logs/server.pid背景 process ID
⚠️ 目前使用 Windows 工作排程器的「登入後啟動」。電腦重開機後需登入 Windows 才會自動啟動。

架構

專案結構

.
├─ index.html          # 主查詢頁面
├─ manual.html         # 使用者手冊
├─ dev-guide.html      # 本頁（維護手冊）
├─ server.js           # 靜態伺服器 port 4173
├─ package.json        # npm scripts
├─ agent.md            # AI 交接紀錄
├─ claude.md           # → 轉址 agent.md
├─ assets/
│  ├─ app.js           # 前端主邏輯
│  ├─ styles.css       # 主查詢頁樣式
│  ├─ manual.css       # 手冊樣式
│  └─ vendor/pdfjs/    # PDF.js 離線版
├─ data/
│  ├─ buildings.json
│  └─ fire-map-index.json
├─ scripts/
│  ├─ build-index.js   # 索引產生器
│  ├─ push.ps1         # 快速推 GitHub
│  └─ windows/         # 背景啟動腳本
└─ 火警圖 PDF/          # 原始圖面（公開 repo）
