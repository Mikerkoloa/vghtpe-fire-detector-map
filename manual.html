使用手冊

先找到圖面，再圈出探測器位置。

本手冊把查詢流程拆成清楚步驟：輸入定址碼、選擇棟別與樓層、在 PDF 中搜尋、更新圖資與 Windows 背景啟動。

快速範例 長青樓 6F M2-66

輸入完整棟別、樓層、定址碼後，系統會直接開啟 PDF 並以粗線圈選文字標籤。

1 搜尋探測器 輸入 M1-66 或完整條件 2 選棟別樓層 不用下拉選單，直接點按鈕 3 查看 PDF 縮放、拖曳、圈選位置 4 維護資料 更新 PDF、重建索引、背景啟動

一般使用

搜尋方式

搜尋欄可以加入一個或多個定址碼標籤，也可以輸入完整棟別與樓層。輸入越完整，系統越能直接定位。

只知道定址碼 M1-66 或 M166

輸入後會變成定址碼標籤，列出所有符合的棟別與樓層。

批次搜尋 M1-66 M2-60

可一次加入多個定址碼標籤，結果會依定址碼分組。

最完整 長青樓 6F M2-66

直接開啟該樓層 PDF，並圈出探測器編號文字標籤。

圖面選擇

從棟別與樓層進入

不知道定址碼時，可以先進入指定樓層，再搜尋目前 PDF 內的定址碼。

1 點選棟別

例如：一門診、二門診、長青樓、重粒子。

2 點選樓層

樓層按鈕會依 RF、樓層、地下層排序。

3 顯示 PDF

第一次進入圖面時，中央會跳出「搜尋定址碼」。

PDF 操作

圈選與移動圖面

圈選目標採用探測器編號文字標籤，使用粗線與橘色標籤，方便在圖面上辨識。

M1-82
滑鼠滾輪

在 PDF 上滾動可放大或縮小。

左鍵拖曳

按住左鍵可移動畫面。

點圈選兩下

快速放大圈選的位置。

存圖

有圈選標記時，可將目前頁面與標記儲存成 PNG 圖片；手機會開啟預覽與分享。

手機操作

兩指可放大或縮小 PDF，放大後可用單指拖曳移動圖面。

維護者

更新 PDF 與背景啟動

PDF 檔案有新增、刪除或替換時，一定要重新產生索引，搜尋結果才會跟著更新。

更新 PDF 後 重新建立索引 
node scripts/build-index.js

會更新 `data/fire-map-index.json` 與 `data/buildings.json`。

本機背景執行 Windows 10 啟動 
npm run win:start
npm run win:status
npm run win:stop

啟動後開啟 `http://localhost:4173`。

重開機自動啟動 註冊工作排程 
npm run win:register
npm run win:unregister

目前設計為「登入 Windows 後自動啟動」。

重要提醒

搜尋不到或位置不對時

  • 確認 PDF 是否已放入 `火警圖 PDF` 資料夾。
  • 更新 PDF 後，必須重新執行 `node scripts/build-index.js`。
  • 如果線上版仍是舊資料，請重新部署 Vercel，並在瀏覽器按 `Ctrl + F5` 強制重新整理。
  • 目前圈選的是文字標籤，不是探測器圖符本體。
